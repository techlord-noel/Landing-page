Secure & Intelligent Examination Management

ExamGuard AI replaces manual, paper-heavy grading processes with an advanced local-network system. Using Gemini Flash AI, it instantly reads student identity and marks from scanned script covers, cross-references records, and computes final results flawlessly.

Built Around Secure, Role-Based Access Control

Super Admin (Cloud Layer)

Hosted on a secure cloud VPS with mandatory 2FA. Super Admins activate/deactivate Admin accounts upon payment confirmation via Mobile Money or bank API.

Admin (Local Campus)

Operates on the school's local network. Manages Record Officers, unlocks Exam Sessions, and triggers security-monitored remark or resit operations.

Record Officer (Campus Core)

Processes student records, uploads CA sheets, photographs/scans script cover sheets, and handles AI confidence verification workflows.

Streamlined Marks & Vision Extraction Workflow

1. Continuous Assessment (CA) Excel Upload

Record Officers upload CA marks using our standardized Excel template (max 30 marks). The system auto-detects academic context and flags missing marks to prevent fraud.

2. Google Gemini Flash Vision AI Scanning

Scans student name, matricule number, and exam marks (out of 70). Achieves 1-2s extraction speed, interprets negative marks (-70 to 70), and falls back to manual validation for ambiguous handwriting.

3. Confidence-Flagged Review Screen

Any field falling below the AI confidence threshold is marked in Red. Officers must explicitly Approve (finalize to master) or Discard (reject with prompt) each entry.

Bank-Grade Security & Offline-First Integrity

Raw SQL & On-Premises Isolation

Local server restricts Admin & Record Officer access strictly to the campus intranet. Uses raw SQL via PostgreSQL 'pg' driver (no ORM) with TLS/HTTPS encryption in transit.

Unalterable Audit Logs & Outbound Tunnels

Maintains strict audit trails (original vs edited marks, editor, timestamp). Connects securely to Cloud VPS using mutually verified certificates or rotated keys via an outbound-initiated tunnel.
